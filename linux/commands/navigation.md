# Navigation Commands

## `pwd`

Prints the path of the current working directory.

```bash
pwd
```

**Example:**

```bash
pwd
```

---

## `ls`

Lists files and directories in the current directory.

```bash
ls
```

**Example:**

```bash
ls
```

---

## `ls -a`

Lists all files and directories, including hidden files.

```bash
ls -a
```

**Example:**

```bash
ls -a
```

---

## `ls -l`

Lists files and directories in long format, including permissions, ownership, size, and timestamps.

```bash
ls -l
```

**Example:**

```bash
ls -l
```

---

## `cd`

Changes the current working directory.

```bash
cd <directory>
```

**Example:**

```bash
cd inhere/
```

---

## `cd ..`

Moves one level up to the parent directory.

```bash
cd ..
```

**Example:**

```bash
cd ..
```

---

## `cd ~`

Moves to the current user's home directory.

```bash
cd ~
```

**Example:**

```bash
cd ~
```

---

## `tree`

Displays directories and files in a tree-like structure.

```bash
tree
```

**Example:**

```bash
tree
```
